# Atlas Obsidian Vault

Open this folder as an Obsidian Vault or copy it to `~/.atlas/vault/`. These CRM records are fictional examples, not customers or revenue.

Start at [[genesis]]. Specialists: [[atlas-ai-native-architect]], [[atlas-sales-os-commander]], [[atlas-gbrain-curator]], [[atlas-editorial-engine]], [[atlas-reality-auditor]].

No credentials belong in the Vault. Runtime installation must never overwrite an existing Vault without an explicit merge plan.
